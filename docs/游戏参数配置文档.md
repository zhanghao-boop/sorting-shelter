### 3.2 签到显示规则 (`streakDay`)

## 四、金币经济系统

### 4.1 关卡奖励计算 (`calcCoinReward`)

| 参数 | 值 | 说明 |
|------|-----|------|
| 基础奖励 | `20` coins | 最低保底 |
| 上限奖励 | `40` coins | 最高封顶 |
| 难度分数上限 | `10` | diffScore 上限 |
| 难度分数公式 | `min(10, floor(opt/3) + max(0, numTypes-3))` | opt每3步+1分；颜色种类超过3种每多1种+1分 |
| 三星加成 | `+5` | 3星额外金币 |
| 二星加成 | `+2` | 2星额外金币 |
| 一星加成 | `+0` | 1星无加成 |
| **最终奖励公式** | `max(20, min(40, 20 + diffScore + starBonus))` | 结果区间 **[20, 40]** |

> **代码位置**：`js/game.js` 第290-299行

### 4.2 首次通关 vs 重复通关

| 场景 | 倍率 | 说明 |
|------|------|------|
| 教程通关 | 固定 `5` coins | 教学关卡专属 |
| 首次通关 | `100%` (baseReward) | 完整奖励 |
| 星级提升 | `60%` (baseReward × 0.6) | 重复通关但星级提升 |
| 重复通关（同/低星） | `12%` (max(3, baseReward × 0.12)) | 防止刷金币，保底3金币 |

> **代码位置**：`js/game.js` 第706-720行

### 4.3 金币等级系数

| 参数 | 说明 |
|------|------|
| `calcCoinReward` 中的 `lvlFactor` | 基于关卡等级影响 diffScore，通过 opt 值间接体现 |
| 关卡越高 → opt 值越大 → diffScore 越大 → 奖励越接近40 |

### 14.2 收藏解锁规则 (v5 — 渐进式阈值)

#### 解锁机制

| 参数 | 值 | 说明 |
|------|-----|------|
| 阈值范围 | **10 ~ 100**（必须是 **10 的倍数**） | 越后面的区域/动物需要的救助次数越多 |
| 判定条件 | `rescueCount[t] >= ANIMALS[t].unlock` | 仅 Classic 模式计入，每管救出 CAP=4 只 |
| 稀有区域标记 | `['Mythic Realm', 'Dreamwood', 'Lake']` | 这些区域的动物解锁后显示稀有光效 |

> **代码位置**：`js/data.js` `UNLOCK_THRESHOLDS` 数组 + `ANIMALS[].unlock` 字段；`js/game.js` 第674行

#### 设计原则

1. **Forest 最易** (10-40) — 新玩家第一个接触的区域
2. **Grassland&Farm 次之** (30-50) — 略微提升
3. **Rainforest 中期** (50-70) — 进入中期后难度爬升
