## 二、Phase 0：即时分享（今天就能做）

> ⏱ 耗时：5分钟 ｜ 💰 成本：0元 ｜ 📈 触达：5-50人

### 2.1 局域网分享（同WiFi）

你已经有 `serve.py`，直接用：

```bash
cd /Users/zh/Desktop/小游戏创新/pet-rescue-mvp
python3 serve.py
```

终端会输出局域网地址，让朋友用手机扫二维码即可玩。

**适用场景**：
- 公司/学校让同事同学试玩
- 朋友聚会现场安利
- 快速收集第一波反馈

### 2.2 公网隧道分享（任何地方的朋友）

```bash
python3 serve.py --tunnel
```

会自动通过 cloudflared 生成公网地址（如 `https://xxx.trycloudflare.com/v2/`），微信直接发链接就能玩。

**前置准备**：安装 cloudflared
```bash
brew install cloudflared
# 或从 https://github.com/cloudflare/cloudflared/releases 下载
```

> ⚠️ 隧道在你的电脑开机时才有效，电脑关机链接就失效了。适合临时分享，不适合长期公开。

### 3.1 🥇 推荐：GitHub Pages（最简单）

| 项目 | 说明 |
|------|------|
| 费用 | 0元 |
| 域名 | `你的用户名.github.io/sorting-shelter` |
| HTTPS | 自动 |

**步骤**：

1. 注册 [GitHub](https://github.com) 账号（已有则跳过）

2. 创建新仓库，命名为 `sorting-shelter`（或任意名）

3. 把 `v2/` 文件夹内容上传到仓库根目录：

   ```bash
   cd /Users/zh/Desktop/小游戏创新/pet-rescue-mvp

   # 初始化git仓库
   git init
   git checkout -b main

   # 把所有v2内容复制到仓库根目录（GitHub Pages需要index.html在根目录）
   ```

- **Mock模式先跑通所有流程**：当前Mock模拟1.2秒广告，正式接入后体验一致

## 六、Phase 4：PWA 化

> ⏱ 耗时：半天 ｜ 💰 成本：0元 ｜ 📈 效果：离线可玩、添加到桌面、D30留存提升30%+

### 6.1 manifest.json

在 `v2/` 目录创建 `manifest.json`：

```json
{
  "name": "Sorting Shelter Pro",
  "short_name": "Sorting Shelter",
  "description": "Sort, stack, and rescue 50 cute animals!",
  "start_url": "./index.html",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#FDF9F2",
  "theme_color": "#FDF9F2",
  "icons": [
    {
      "src": "./icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "./icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

在 `index.html` 的 `<head>` 中引用：
```html
<link rel="manifest" href="./manifest.json">
```

### 6.2 Service Worker（离线缓存）

创建 `sw.js`：

```javascript
const CACHE = 'ss-v1';
const ASSETS = [
  './',
  './index.html',
  './css/style.css',
  './js/game.js',
  './js/data.js',
  './js/ads.js',
];

self.addEventListener('install', e => {
  e.waitUntil(
    caches.open(CACHE).then(cache => cache.addAll(ASSETS))
  );
});

self.addEventListener('fetch', e => {
  e.respondWith(
    caches.match(e.request).then(r => r || fetch(e.request))
  );
});
```

在 `game.js` 中注册：
```javascript
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('./sw.js');
}
```

### 6.3 效果

- 用户第二次打开加载速度提升 80%+
- 可添加到手机主屏幕，像原生 App
- 无网络也能玩（基础功能）
- Chrome/Safari 都支持

## 七、Phase 5：微信/抖音小游戏上架

> ⏱ 耗时：2-4周（含软著申请） ｜ 💰 成本：0-1500元 ｜ 📈 触达：微信13亿用户

### 7.1 前置条件

| 条件 | 说明 | 时间 |
|------|------|------|
| 软件著作权 | 微信/抖音小游戏必须 | 自己申请1-2月（免费），代办3-5天（500-1500元） |
| 个人主体 | 个人可注册但不能开内购 | — |
| 游戏内容合规 | 无违规内容 | — |

### 7.2 微信小游戏接入流程

1. 注册 [微信公众平台](https://mp.weixin.qq.com) → 选择小程序 → 完成认证

2. 下载微信开发者工具

3. 将当前游戏适配为微信小游戏：
   - 去掉 `document.*` 全局操作，改用小游戏 API
   - `<canvas>` 渲染替代 DOM 操作（这是最大的改动）
   - 广告接入：你的 `ads.js` 已有 `wechat` Provider，可以直接切

4. **特别注意**：你的游戏是**纯DOM渲染**（试管、按钮都是HTML元素），这在小游戏环境中需要改写为 Canvas 渲染。这意味着：
   - ✅ 游戏逻辑（game.js 中的状态管理、BFS验关等）可以直接复用
   - ⚠️ 渲染层（render/renderTube/renderCollection等）需要重写为 Canvas API 或使用适配库

5. 提交审核 → 审核通过 → 上线

### 7.3 降低小游戏适配成本的方案

| 方案 | 说明 | 推荐度 |
|------|------|--------|
| 用 `web-view` 组件 | 微信小游戏支持 web-view 加载H5页面 | ★★★ 最快，但有限制 |
| 用 Cocos Creator 重写 | 完整迁移到游戏引擎 | ★ 成本高 |
| 保持 H5 Web 版不转小程序 | 专注于网页端和平台分发 | ★★★ 当前阶段推荐 |

> 💡 **建议**：现阶段先专注于 H5 Web 端（GitHub Pages + CrazyGames + itch.io），小游戏版本等 H5 数据跑正了再考虑适配。Web 端的变现能力不输小程序。

### 7.4 抖音小游戏

流程类似微信，额外注意：
- 抖音强调短视频传播（录屏分享）
- 你的游戏救出动物的瞬间天然适合短视频素材
- 可以对接抖音发行人计划（让达人帮你推广，按效果付费）

## 八、Phase 6：Google Play 上架

> ⏱ 耗时：1-2周 ｜ 💰 成本：$25一次性 ｜ 📈 触达：安卓全球用户

### 8.1 方案：PWA 包装

将你的 PWA 版游戏用 [PWA Builder](https://pwabuilder.com) 或 [Apache Cordova](https://cordova.apache.org) 打包成 APK，上传到 Google Play。

**步骤**：

1. 注册 Google Play 开发者账号（$25一次性费用）

2. 用 PWA Builder 将你的网站 URL 转换成 APK：
   - 输入你的 GitHub Pages 网址
   - 自动生成签名的 APK/AAB
   - 可选添加推送通知

3. 在 Google Play Console 创建应用：
   - 上传 AAB 包
   - 填写描述、截图（手机竖屏 1080×1920）
   - 设置内容分级问卷
   - 设置隐私政策链接

4. 提交审核，1-2天即可上线

### 8.2 注意

- Google Play 上的 H5 游戏变现需要通过 AdMob（Google 自己的广告平台）
- AdMob eCPM 优于国内平台，但面向海外用户
- 需要GDPR隐私合规弹窗（面向欧盟用户）

## 十二、常见问题 FAQ

### Q1：我一个人能搞定所有这些吗？

可以。当前游戏已经开发完成，剩下的部署和分发工作大部分是**配置和提交表单**，不需要写代码（除了广告SDK接入）。

### Q2：先做哪个平台最重要？

**第一优先级：GitHub Pages（固定网址）+ CrazyGames（免费流量）**。
有固定网址才能分享，有平台才能获取用户。

### Q3：广告多久能赚到钱？

取决于DAU。粗略估算：
- DAU 100 → 月入 ≈ ¥50-100
- DAU 1000 → 月入 ≈ ¥500-2000
- DAU 10000 → 月入 ≈ ¥5000-20000

### Q4：需要注册公司吗？

不需要。所有推荐的第一步路径（GitHub Pages、itch.io、CrazyGames、Cloudflare Pages）都支持个人身份，无需营业执照。

### Q5：游戏文件里有我的个人信息吗？

没有。游戏是纯前端静态文件，不包含任何服务器端逻辑或个人数据。用户数据存储在各自的浏览器 localStorage 中。

### Q6：需不需要做多语言？

当前游戏是英文，已经适合出海。如果要做国内市场：
- 最小成本方案：在 `game.js` 加一个 `LANG` 变量和翻译映射，切换中英文
- 建议在第2-3个月数据跑正后再投入i18n

### Q7：服务器成本呢？

零。你的游戏是纯静态前端，不需要服务器。GitHub Pages / Cloudflare Pages / Vercel 都是永久免费的静态托管。

### Q8：如果CrazyGames审核不通过怎么办？

最常见的拒绝原因：
- 缺少 mute 按钮 → 加一个 BGM 开关（你已经有 `#bgm-btn` 了）
- 没有 loading 完成回调 → 加 `sdk.loadingFinished()`
- 外部链接太多 → 去掉不必要的跳转

一般修改后重新提交即可通过。
