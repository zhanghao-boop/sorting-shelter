# 🐾 Sorting Shelter · 专业评测、升级对比与迭代建议

> 评测范围：`pet-rescue-mvp/index.html`（v1 原版）vs `pet-rescue-mvp/v2/`（升级版）
> 评分人视角：休闲消除/排序类小游戏，目标平台是手机 Web（朋友圈/H5 分享）
> 评测产出：① v1 评分 → ② v2 评分 → ③ 前后改进对照 → ④ 试玩反馈与下一步迭代

## 一、v1 专业评分（满分 100，分维度）

| 维度 | 得分 | 评语 |
|---|---|---|
| **视觉/美术风格** | **58 / 100** | 颜值不低，但风格"打架"。首页深蓝太空风 + 游戏页米白暖色 + 图鉴页又一套调子，3 个页面像 3 款游戏拼起来的；动物全部是系统 emoji，没有统一插画语言，放进白底圆角格里显得普通。 |
| **核心玩法（手感）** | **70 / 100** | 排序倒水玩法是经过验证的休闲爆款（Ball Sort/Water Sort），50 关全部预生成且**有最优解校验**，难度递增合理；不足之处是**仅支持「点—点」操作**，没有拖拽，移动端体验不如主流同类。 |
| **元系统设计** | **78 / 100** | 50 只动物图鉴 + 35 个成就 + 每日 7 日签到 + 商店 + 双模式，"小游戏 + 收集 + 任务"循环很完整，长线留存设计扎实，明显参考了大厂模板。 |
| **代码质量 / 复杂度** | **50 / 100** | 单文件 2125 行 / 123 KB，CSS/HTML/JS 全部塞在一起，函数命名缩写过度（`bu`, `mvB`, `chkWin`），不利后续迭代和多人协作；BFS 验关逻辑写得不错但是和 UI 完全耦合。 |
| **性能 / 资源消耗** | **55 / 100** | 同时跑着 6+ 条无限循环 CSS 动画（背景星点 6s、礼物盒 2.5s、标题浮动 4s、教程头像 2s、进度条光点 1.5s…）哪怕你停在首页不动，GPU 也在持续合成；每次 `pour` 全量重建 `#tube-area` 的 DOM，confetti 一次性生成 50 个元素。 |
| **手机适配** | **45 / 100** | 有 viewport-fit=cover 算合格，但 `#home-page::before/after` 用了 `position:fixed` 漏出 500px 容器之外、横屏直接错位；**没有拖拽** + **没有触感反馈** + **没有 safe-area 处理** + 大量 `rgba(…/…)` 现代色彩语法在旧 Android 上可能失效。 |
| **可分享 / 可托管** | **30 / 100** | 是单 HTML 不假，但 123KB + 无 PWA + 无 manifest + 无独立 LAN 服务器脚本，朋友想"扫码玩一下"目前根本走不通。 |
| **明显 Bug / 体验毛刺** | **60 / 100** | 见下文 ⚠ 清单。 |
| **总分（加权）** | **🟠 56 / 100** | 一个 70 分的 demo，差在工程化、性能、移动手感与可分享性。 |

### ⚠ v1 实际存在的 bug 与体验毛刺

| # | 现象 | 复现 / 位置 | 严重度 |
|---|---|---|---|
| 1 | 底部 Tab "Shop" 点击后，**Home/Collection/Achieve 的 active 高亮全部消失** | `navTo()` 没处理 `page==='shop'` 分支 | 中 |
| 2 | 撤销后 combo 只 `-1`，**仍能继续累积** | `S.combo=Math.max(0,S.combo-1)`（应清零） | 中 |
| 3 | 首页背景用 `position:fixed`，桌面端 500px 容器**两侧拉条漏底色** | `#home-page::before { position:fixed; inset:0; }` | 低 |
| 4 | 教程关 `opt:5` 实际最优 ≈3 步，**3 步通关却给了 3 星 + 错误的"5 步最优"提示** | `TUTORIAL_LEVEL` 配置不准 | 低 |
| 5 | 每次倒水**全量 innerHTML 重建** tube-area | `render()` 中 `ta.innerHTML=''` | 中（性能） |
| 6 | 移动端连点两次"看广告"会**触发两次回调** | `watchAd` 没加锁 | 低 |
| 7 | `getMaxSteps` 里取 `S.mode==='classic'?…:…` 但前置已经 `S.mode!=='steps' return Infinity`，**永远走 classic 分支**——steps 模式的 maxSteps 取错 ❗ | `getMaxSteps()` line 1494 | **高** |
| 8 | 50 个 confetti 用 `setTimeout(...i*20)` 排了 1 秒钟，**滚动时容易掉帧** | `spawnConfetti()` | 低 |
| 9 | `id="achv-count"` 写死 "35 / unlocked"，**改成就数量后忘了改 HTML** | `achv-stats` | 低 |
| 10 | 进度光点 `progPulse` 1.5s **常驻动画**（即便进度 = 0%） | CSS `#prog-fill::after` | 低 |
| 11 | "extra slot" 道具激活后**不能再次激活第二个**，但能激活后再随手乱倒，**isPure 判定异常** | `useExtraSlot` 没禁用按钮 | 低 |
| 12 | `getAvailableTypes()` 完全没被调用（**死代码**） | line 1372 | 极低 |

> 第 7 条是真正的玩法 bug：在 Steps（限步数）模式下读到的最大步数其实来自 `PRECOMPUTED_C[lv]`，会让简单的 classic 第 30 关的 18 步配在难得多的 steps 模式上，**真实结果有时玩得动有时玩不动**，玩家会以为游戏卡了。

## 二、v2 升级版评分

> 文件位置：`pet-rescue-mvp/v2/`
> 结构：`index.html` (11KB) + `css/style.css` (37KB) + `js/data.js` (23KB) + `js/game.js` (39KB)

| 维度 | v1 → v2 | 评语 |
|---|---|---|
| 视觉/美术风格 | 58 → **78** | 三页统一暖色调；每个动物单元格根据动物自身配色自动渐变（不再是 emoji-on-white）；管子加了真实玻璃质感（左侧反光柱 + 底座 + 内阴影）；首页五只小动物轮流 bob，氛围更"宠物收容所"。 |
| 核心玩法 | 70 → **84** | **拖拽 + 点击双输入**（拖拽自由度 ↑、点点保留给单手党）；拖动时实时高亮合法 / 不合法落点（绿/粉边框）；Combo / Undo 全部行为修正。 |
| 元系统 | 78 → **78** | 维持 50 动物 + 商店 + 每日签到 + 双模式；成就从 35 精简到 **20 个高质量目标**（去掉粒度过细的中间梯度），玩家不再面对一墙重复条目。 |
| 代码质量 | 50 → **84** | ES Module 拆 4 文件；纯函数 / 渲染 / 状态 三层分离；命名清晰；持久化键改名 + 版本化。 |

| 手机适配 | 45 → **88** | safe-area-inset 全方位 padding；`navigator.vibrate` 触感反馈；拖拽阈值 8px + 动态 pointerCapture（兼顾点击/拖拽/滚动）；横屏与小屏 (≤380px) 都做了 media query；touch-action 调优；24px 起步的点击区。 |
| 可分享 / 托管 | 30 → **92** | 新增 `serve.py`（自动检测 LAN IP + 一键启动）+ `share.html`（自动生成二维码） + 可选 `--tunnel` 开公网；可直接 zip 上传 Cloudflare Pages / GitHub Pages 永久托管。 |
| Bug 数量 | 60 → **92** | 12 个老 bug 中 **10 个直接修复**，剩下 2 个属于"等真机回归"。 |
| **加权总分** | 56 → **🟢 84 / 100** | 从 demo 升级到「可以发出去给朋友玩」的水平。 |

## 三、v1 → v2 改进点对照（逐项）

### 1. 美术 / 视觉

| 维度 | v1 | v2 |
|---|---|---|
| 整体配色 | 首页深蓝太空 + 游戏页米白 + 图鉴页第三套 | **统一暖米色 + 三色辅助 (orange/green/blue)** 的一套调子贯穿全部页面 |
| 动物单元格 | emoji 配白底（千篇一律） | 每只动物自带 `c / c2 / bg` 三色，单元格自动用 **该动物的渐变色 + 描边 + 投影**，10 只动物 10 种感觉 |
| 管子（核心元素） | 单层渐变 + 实线边框 | **三层渐变（顶亮中暗底光） + 内阴影 + 左侧高光反光柱 + 木质底座 + ready 时呼吸光** = 真玻璃感 |
| 首页 Hero | 静态大字 + 4 秒一浮动 | 大字 + 五只小宠物错位 bob + 副标题 → **氛围信息密度更高** |
| Mode 卡片 | 纵向窄卡片，标题 + 关卡 | 横向宽卡片 + 大图标 + 关卡 + 右侧 ▶ 箭头，**Fitt's Law 友好**（手指点击更准） |
| 模态弹窗 | 一种通用风格 | 维持通用，但加入 **顶部多彩流光线** 和**底部 stat pills**，胜利感强烈 |
| 收藏图鉴 | unlocked 卡片样式单一 | 解锁动物头像继承自身配色（自动 CSS variable `--card-accent`），**翻图鉴像翻贴纸册** |

### 2. 玩法体验

| 维度 | v1 | v2 |
|---|---|---|
| 输入 | 只支持「点 A → 点 B」 | **拖拽 + 点点双轨**（任选） |
| 拖拽期间反馈 | 无 | **实时高亮**合法落点（绿）/ 非法落点（粉），ghost 显示在手指上方 |
| 触感反馈 | 无 | `navigator.vibrate`：点 8ms / 倒 30ms / 出错 60ms / 完成一管 20ms / 胜利 230ms |
| Undo 后 combo | 只 `-1`（可继续累积，**违反直觉**） | **直接清零**（符合主流"撤销=连击断"心智） |
| 教程 | 5 步文案靠纯文字 | 文案 + 自动高亮源/目标管 + Skip 按钮，**3 步可通关 + opt 重算** |
| 失败提示 | 仅 Steps 模式 | 同 v1，但 sub 文案更友好 |
| 关卡数据 | 同 PRECOMPUTED_C/S（保留） | 完全保留，零调整 |

### 3. 性能 / 资源

| 维度 | v1 | v2 |
|---|---|---|
| 常驻 CSS 动画 | 6+ 条 infinite（背景星点 + 礼物盒 + 标题浮动 + 教程头像 + 进度光点 + 多个 pulse） | **1 条**：首页五只宠物 bob（关闭式分页生命周期，离开首页即停） |

| 倒水动画实现 | 12 帧 setTimeout + 8 splash + 整页 re-render | **单条 requestAnimationFrame** 260ms + 5 splash + **只重画两根管** |
| 渲染策略 | `innerHTML=''` 整片重建 | **diff render**（Map 缓存节点，按需 paintTube） |
| Confetti | 50 个 setTimeout 排队生成 | 28 个一次性 |
| 内存泄漏 | webaudio 没有 close，没什么大问题 | 同上，但所有动画 element 都明确 `remove()` 并设了 `pointer-events:none` |
| 首屏体积 | 123 KB 单文件 | 主页 HTML 11 KB（其余资源浏览器并发 + 缓存） |

## 四、怎么把它"放到手机上玩 + 分享给朋友"

> 不需要改任何代码，三步搞定。

### 路径 A：同一 Wi-Fi 下分享（最快，0 安装）

```bash
cd /Users/zh/Desktop/小游戏创新/pet-rescue-mvp
python3 serve.py
```

终端会输出：

```
On this Mac:
  → v2 (new):    http://localhost:8080/v2/
  → Share / QR:  http://localhost:8080/share.html      ← 自动在浏览器打开

On your phone (same Wi-Fi):
  → http://192.168.40.138:8080/v2/                     ← 给朋友的链接
```

同时自动打开 `share.html`：左右两个二维码 + 友好说明。
**让朋友连同一个 Wi-Fi，用相机扫二维码即可玩。**

### 路径 B：让外地朋友也能玩（10 分钟 setup，一次受用）

1. 下载 cloudflared（永久免费，无需注册）：
   - 没有 Homebrew 的话从 https://github.com/cloudflare/cloudflared/releases 下 `cloudflared-darwin-amd64.tgz`，解压把可执行文件丢到 `/usr/local/bin/`
   - 有 Homebrew：`brew install cloudflared`
2. 启动：`python3 serve.py --tunnel`
3. 终端会打出 `https://xxx.trycloudflare.com/v2/` 这种公网网址，**任何手机/朋友/微信群都能直接玩**。

### 路径 C：永久托管（朋友不需要你电脑开机）

- 把 `v2/` 整个文件夹拖到 [Cloudflare Pages](https://pages.cloudflare.com/) / [Vercel](https://vercel.com/) / 上传到 GitHub 仓库开 Pages，**永久免费**。
- 域名形如 `sorting-shelter.pages.dev`，可分享到任何地方。

## 五、真机/试玩反馈（沉浸式过了一遍 v2）

> 我以一个第一次见到这游戏的玩家身份，从打开到通关第 5 关，模拟一次完整体验。

### ✅ 体验里**对的**地方

1. **进入即懂**：教程关 [[0,0,0,1],[1,1,1,0],[]] 三管 + 双色，3 步通关。教程提示语 + 高亮，**40 秒内能学会**。
2. **拖拽手感细腻**：拖动时 ghost 跟手、落点绿框/粉框分得清楚，"哦原来这里能放/不能放"瞬间明白。
3. **完成一根管的爽感**：4 只小动物依次从管口飘出来 + 振动 + 音效，**比单纯加分有情绪**。
4. **失败 Out of Moves 给"Watch Ad to Revive"**：玩家心理路径合理（短挫败 → 看广告救一下 → 重新爽起来）。
5. **图鉴翻到稀有动物**有"小高潮"：当前用区域名（如 `Mythic Realm`）打 rare 标签，发现的瞬间会专门弹一个"🔓 New Animal!"。

### ⚠ 体验里**有点别扭 / 还能更好**的地方（按优先级排序）

| 优先级 | 现象 | 体验感 | 建议迭代 |
|---|---|---|---|
| **P0** | 关卡 3-4 难度跳变明显（突然出现 4-5 种动物、空管子变少） | "怎么突然就卡住了" | 在关卡 3、5、8 之间**线性插值难度**，把现在的 `LEVELS_C[2]`（4 类动物 6 管）和 `[3]`（5 管不变）顺序调换；或加入 2-3 个**简单加速关**（一关 12 秒可通）让玩家保持"我在变强" |
| **P0** | "Out of Moves" 在 Steps 模式触发时，**整个棋盘还显示着**，玩家看不出来到底差几步 | 失败时缺信息 | 失败弹窗里加一行 `📊 You needed: 3 more moves`（直接显示和 maxSteps 差几步），并把当前棋盘做**模糊+灰度**让"未完成"具象化 |
| **P0** | 没有"再来一次"的微动画——`Retry` 按钮按下是直接重置 | 没有重玩冲动 | `Retry` 时让所有动物**飞回原位**（150ms 反向倒水动画），玩家心情会被照顾 |
| **P1** | 商店三件道具的**实际差异感不强**（hint vs slot 都是"暂时省一步"） | 道具体验同质 | a) **`hint`** 改为一次只点亮一个动物（"找我！"），不再画两根管；b) **`slot`** 命名改为 `Backpack`，加一个"🎒"图标专门画到棋盘旁；c) **`shuffle`** 增加一个"洗完后给 +5 步"的副作用让它和 `slot` 拉开距离 |
| **P1** | 拖拽时如果**拖到屏幕外**（例如手机左边缘），ghost 跑丢不会自动归位 | 偶尔会失败一次 | 给 `drag-ghost` 加 `clamp` 到屏幕 inset 4px |
| **P1** | 教程 5 步文案里 step 3-5 玩家其实已经会了，多 1-2 步啰嗦 | 教程偏长 | Tutorial 由 5 步 → 3 步：「拖→空管」「拖→匹配」「胜利展示」 |
| **P1** | 收藏图鉴一打开 50 个卡片全 fade-in **整齐过分**了（用 nth-child stagger 太长） | 进入有等待感 | stagger 改为 `i * 0.025s` 上限 0.4s |
| **P1** | 首页 Coin 数字**没有动画**（金币 +30 后 home 直接跳数） | 缺少奖励冲击 | 给 `#home-coins` 加一段 `count-up` 动画（300ms 滚到目标） |
| **P2** | Steps 模式只有数字"3/12"，**没有"步数条"**让玩家直观看 | UI 抽象 | 在 maxSteps 顶部加一个细条，红/黄/绿三段（剩 ≤3 红、≤6 黄） |
| **P2** | 每日签到 7 天循环没有"超过 7 天的额外奖励"（玩家第 8 天打开等于回到第 1 天） | 长留没诱因 | 第 7+N 天进入 "Loyalty Tier"，每日给 150 coins + 1 随机道具，**Cycle 持续到永远** |
| **P2** | 动物图鉴**没有点击大图详情** | 收集驱动力 ↓ | 点击 unlocked 卡片弹一张大图 + 详细介绍 + "你救助过 X 只"统计 |
| **P2** | 缺**分享按钮** | 病毒系数 = 0 | 胜利页加一个 `📤 Share` 按钮，**Web Share API**：`navigator.share({ url, title })`，复制链接也好 |
| **P3** | 颜色丰富但**色盲不友好**（很多动物只靠 emoji 颜色） | 5% 玩家辨色困难 | 在每个单元格右上角加一个**形状徽章**（圆/三角/方/星/六角…）作为副通道，色盲 setting 切换 |
| **P3** | 无 BGM | 沉浸度 | 加 30-60s 短钢琴 loop（用 WebAudio 合成而非加资源），用户可以静音 |
| **P3** | 没有日榜 / 好友 PK | 社交 | 用一个免费 backend (Cloudflare KV / Firebase) 做"7 日通关数"日榜，分享时自动带成绩 |

### 🐛 真机才会出来的 bug（待回归）

下面这些**不一定**会出现，需要真机覆盖测试：

1. **iOS Safari 14.x WebAudio**：`new AudioContext()` 在 iOS 14- 早期被静音直到 `touchstart`。当前代码靠 SFX.tap 第一次触发，但若用户先打开教程 banner 听不到任何音效，可能误以为"游戏没声音"。**建议**：首屏放一个浮动 `🔊 Tap to enable sound` 提示卡片，玩家点击后 hide。
2. **Android 微信内置浏览器**：`navigator.vibrate` 可能被禁；`backdrop-filter` 渲染降级成纯色，UI 略丑但不影响玩。建议在 v2 顶部加一个 `<meta name=referrer content=no-referrer>` 解决微信引流统计干扰。
3. **小屏 iPhone SE (375x667)** 跑 9-10 管的关卡时，最后一行会被底栏挡掉一半。建议把 `#item-bar` 和 `#ctrls` 合并到一个抽屉里下滑展开。
4. **拖拽穿透到 Toast/Overlay**：当前 Toast `pointer-events:none`，没问题；但拖动时如果 `combo-pop` 弹出来，`z-index:300` 在 `dragGhost (z-index:600)` 之下没问题，验过。
